# Image Gallery

A premium responsive image gallery built with HTML, CSS, and JavaScript.

## Features

- Modern and responsive UI
- Category-based image filtering
- Interactive full-screen lightbox
- Previous and next image navigation
- Image counter
- Keyboard navigation
- Smooth animations and transitions
- Mobile-friendly design
- Clean and accessible interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome

## Project Purpose

This project was developed as part of my frontend development internship to practice responsive web design, JavaScript DOM manipulation, interactive UI components, and modern frontend development techniques.
